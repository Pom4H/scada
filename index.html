    Файлы проекта

    SCADA playground

    Один проект — один TypeScript файл

    Редактор читает декларации DSL. Перетаскивание, свойства и соединения изменяют исходный текст через TypeScript AST. Комментарии и остальной код сохраняются. Ctrl / ⌘ Z отменяет действия в коде и на схеме.

    const p = pump("P-101", { x: 300, y: 280, rpm: 1500 });
const v = valve("V-101", { x: 700, y: 80, opening: 76 });
const line = connect(p.outlet, v.inlet);
tap(line, pressure("PT-101", { value: 5.8 }));

    Мышь и клавиатура

    Перетащите оборудование для перемещения. Выберите его для изменения состояния. Выходной порт → входной порт создаёт связь. Прибор добавляется на выбранную трубу. Колесо — масштаб; фон или Space + перетаскивание — панорама; F — вписать; Delete — удалить выделенное. Перемещение стрелками: 10 единиц, Shift + стрелка: 1.

    Вычисляемые координаты

    x: GRID * 3 читается, но заблокировано для мыши: редактор не заменяет формулу числом. Для визуального редактирования используйте числовой литерал. Разрешены const, арифметика + − * /, импорты функций DSL, connect и tap. Произвольный JavaScript, циклы, сеть и DOM не выполняются.

    Модель расхода

    Для полного последовательного контура с одним насосом: Q = 12 × rpm / 1500 × произведение открытий клапанов. Закрытый клапан, пустой резервуар и trip насоса обнуляют расход. Stale / bad дают неизвестное значение. Незавершённые линии не имитируют течение. Давление и температура задаются независимо — это не расчёт гидравлики и теплопередачи.

    Хранение

    Автосохранение хранит только исходный TS в этом браузере. Кнопка ↓ .ts сохраняет файл на диск; ↓ HTML создаёт автономную анимированную схему. Общая ссылка содержит код в URL-фрагменте. Не добавляйте в него пароли и реальные секреты оборудования. Сервер демо запускается командой npm run demo. Укажите его адрес и токен из консоли, затем подключитесь явно. Токен хранится только в памяти вкладки. Сервер продолжает сценарий при паузе анимации и закрытии вкладки. История и прогоны сохраняются в SQLite. Кнопка «В TS» записывает только адрес и выбранный проект/прогон; «Поделиться» включает выбранный прогон в ссылку. Синтетические данные не являются измерениями реального оборудования.
